# Golf Mk4 — referência visual local

O teste inicial de uma roda foi sucedido pela integração atual:
[GOLF_INTEGRATION.md](GOLF_INTEGRATION.md).

F5 agora abre `world/garage_golf_test.tscn`, com quatro rodas independentes,
20 parafusos de 17 mm, contato dos pneus com o chão, capô importado articulado,
cofre reposicionado e controles LMB para pegar / G para soltar.

O documento atual contém medidas, transformações, limites conhecidos, arquivos,
testes e capturas. As instruções antigas de manter LMB, deslocar o carro 0,485 m
ou usar apenas a roda FL não se aplicam mais.

A cena anterior e os arquivos de origem foram preservados. O Golf continua
sendo uma referência temporária não comercial, excluída do pacote de produção.
